# Glossary

- pandas: a Python library for working with tables.
- pd: the alias used for pandas in the notebook.
- DataFrame: a table in Python, with rows and named columns.
- Variable: a name referring to a value or object; df refers to the loaded table.
- CSV: a text file containing a table, with comma-separated fields.
- Row: one customer record in this dataset.
- Column: one kind of information, such as credit limit.
- head(): returns the first five rows by default without removing other rows.
- Notebook: a file containing explanations, executable code cells, and outputs.
- Kernel: the Python program that runs notebook cells.
- NT$: New Taiwan dollars, the dataset's currency.
- Credit limit (X1): amount of credit granted; not money the customer owns.
